# 组织文化

## 定义

**文化（Culture）**：群体成员**默契共享**（implicitly held）的**信念与假设**系统。**组织文化（Organisational Culture）**：员工在组织内共享的信念与假设。

**关键属性**：文化是**Implicit Control System（隐式控制系统）**——补充**Explicit Control System（显式控制系统）**（规则、职位手册、法律）覆盖不到的所有情境。

## 关键点

### 隐式 vs 显式控制系统

| | Implicit（文化） | Explicit（规则/结构） |
|---|---|---|
| 具体度 | 抽象 | 具体 |
| 覆盖范围 | 覆盖**所有可能情境**的通用思维方式 | 只覆盖预定义"正常情境" |
| 例子 | 文化、道德 | 职位手册、组织架构、法律 |
| 何时起作用 | 显式规则填不满时 | 情境符合规则时 |

**关键洞察**：任何 explicit 系统都不可能覆盖所有情境（**规则的不完备性**）。**文化填补空白**——员工遇到规则未定义的情境时，依靠"我们这儿的人会怎么做"作出判断。这是**为什么改变文化如此困难**（它太抽象，无法用规则直接改写）。

### 文化的两个维度

**Cultural Characteristics（文化特性）**——文化的**内容**：

- Individualism / Collectivism
- Adaptability（适应性）
- Detail Orientation（细节导向）
- Results/Outcome Orientation（结果导向）
- People/Customer Orientation（人本/顾客导向）
- Collaboration/Team Orientation（协作/团队导向）
- Integrity（正直）

**Culture Strength（文化强度）**——群体对特性的**执行程度**。

**Cultural Tightness-Looseness**（紧-松尺度）：

$$\text{Tightness} = \text{number of norms and rules} + \text{strength of reinforcement}$$

- **Tight 文化**：规范多、执行严（新加坡、日本、德国）
- **Loose 文化**：规范少、容忍差异（荷兰、以色列、巴西）

紧松各有优劣：紧文化在标准化生产/协调下更强；松文化在创新/适应新环境下更强（[[innovation-and-diffusion]]）。

### Artefacts（人工物）— 文化的可见部分

*"你看得到、听得到、感受到的部分"*：语言、符号、故事/神话、仪式、着装/制服、技术、结构、物理环境……

Artefacts 是文化的**冰山一角**——真正驱动行为的信念与假设潜藏在下面。企业文化改造常犯的错：**只换 artefacts（重新装修办公室、发文化 T 恤）而不改变底层信念** → 徒劳。

### Norm（规范）

**"正常情境下的行为模板"**。Norm 桥接抽象文化与具体行动：

- 文化定义"什么算重要"
- Norm 定义"具体在情境 X 下人应该做什么"

Norm 与 explicit rules 的区别：**Norm 不写在纸上**，但违反有**社会代价**（怪异、被排挤、被"教育"）。

### 起源的三种视角

关于文化**为什么会是这样**，学界有三派互补的解释：

1. **Functionality Perspective（功能主义）**：文化被创造是因为**它对群体有益**——包括 **Cultural Darwinism**（"最适者生存"）：外部环境变化 → 文化随之变化 → 助组织适应
2. **Leader-Trait Perspective（领袖特质）**：领导者基于**自己的人格**创造文化，与功能性无关（不为利益相关者需求）
3. **Cultural Transfer Perspective（文化传承）**：文化**通过领导者传播**——领导者带过来他们过去所在群体的文化。他们只用**available information**（[[perception-and-bias]] 的可得性偏差），所以带来的是熟悉的过去

**综合评价**：*领导者的确会考虑功能性，但常常失败*，因为：

- Bounded Rationality（[[groups-and-decisions]]）：认知能力有限
- Availability Bias：只基于容易想到的信息判断

所以现实的文化 = 部分功能 + 部分领袖特质 + 部分历史继承的杂糅。

### Reverse Causality（反向因果）

*人**选择**加入哪种文化的组织*——员工-组织匹配不完全由组织"塑造"员工，也由员工"选择"组织。这就是 **[[person-org-fit-and-social-learning]]** 与 **ASA Theory** 的核心：

**Attraction-Selection-Attrition (ASA) Theory**：

- **Attraction**：个体被人格与自己相近的组织文化吸引
- **Selection**：组织倾向选择人格与自己文化相配的候选人
- **Attrition**：错配的员工更容易离职

**长期效应**：ASA 循环让组织的员工人格分布**逐渐同质化**——文化越强，同质化越明显。副作用：**思维多样性下降** → Groupthink 风险上升 → [[groups-and-decisions]] 里的失败机制。

### 社会化过程（Socialisation）— 新员工文化内化

**三阶段**：

1. **Prearrival**（预到达）：加入前学习文化——招聘材料、面试印象、朋友描述
2. **Encounter**（接触）：入职后通过**观察**他人的言语和行为学习——培训、辅导、成员身份
3. **Metamorphosis**（蜕变）：改变自己的思想和行为**与组织文化对齐**

**结果**：原本背景各异的员工**趋同于组织规范**、彼此愈发相似。

**社会化的两面性**：

- ✅ 让组织协作更高效、减少摩擦
- ❌ 抑制个性、压制建设性异见（Groupthink 温床）

### 改变文化为何难

- 文化是**隐式**的 → 你没法直接"发命令改变文化"
- 文化通过 ASA 自我强化
- Artefacts 易改，底层信念难改
- 领导者的 Bounded Rationality 让他们高估自己改造文化的能力

有效的文化改造通常需要**多年**的**新招聘 + 新叙事 + 新流程 + 新领导层示范**多管齐下——不是喊口号能做到。
