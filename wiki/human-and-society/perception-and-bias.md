# 感知与认知偏差

## 定义

**感知（Perception）**：个体**解读**和**组织**感官印象，赋予环境**意义**的过程。感知**不是**对物理世界的镜像——它是**主动构建**且**选择性**的。

对同一客观刺激不同人感知不同 → **认知偏差**（perceptual/cognitive biases）——系统性偏离理性的模式。

## 关键点

### 感知的两个基本维度

**认知类别的形成方式**：

- **Relationship-based**（家族相似）：根据整体相似度归类
- **Rule-based**（明确规则）：根据显式判定规则归类

**观察焦点**：

- **Holistic**（整体）：先看整个场景
- **Analytic**（分析）：聚焦目标对象、拆解分析

这两个维度上的差异部分是**文化**决定的（e.g. 东亚更 holistic 与 relationship-based；西方更 analytic 与 rule-based）——不是"哪个更好"，而是**同一客观刺激被解读为不同东西**。

### 为什么感知不可靠

- **选择性注意**：我们只挑最相关、最重要的信息
- **有限容量**：短期记忆和注意力都是稀缺资源
- 结果：**同样的刺激** → **不同的意义** → **不同的行动**

对组织的含义：*微小的感知差异 → 显著的决策差异*——所以 OB 研究才要重视"人怎么看"，不只是"实际是什么"。

### 七大认知偏差

| 偏差 | 定义 |
|---|---|
| **Anchoring**（锚定） | 过度依赖最初信息，后续调整不足 |
| **Status-quo**（现状） | 避免改变的倾向 |
| **Sunk-cost**（沉没成本） | 继续投入已花时间/金钱的错误项目 |
| **Confirmation**（确认） | 寻找符合过往判断的信息、忽视反驳信息 |
| **Overconfidence**（过度自信） | 主观信心 > 客观准确性 |
| **Availability**（可得性） | 用最容易想到的信息做判断 |
| **Hindsight**（后见之明） | *事后*错误地相信自己*事前*就能准确预测 |

**关键洞察**：偏差**不是低智商的结果**——它们是**认知捷径（heuristic）**的副作用，人在低时间/低认知资源下不得不用捷径。这是 [[groups-and-decisions]] 里 Bounded Rationality 的具体表现。

### Prospect Theory（前景理论）

Kahneman & Tversky 1979 —— Kahneman 因此获诺贝尔经济学奖。研究框架偏差（framing bias）。三条关键假设：

1. **相对参考点评估**：人不评估绝对水平，而是相对**参考点**（e.g. 现状、期望、他人）
2. **收益中风险规避、损失中风险追求**：面对确定收益优先"稳"；面对确定损失反倒"赌"
3. **损失厌恶**：$|\Delta \text{损失效用}| > |\Delta \text{等额收益效用}|$——大致 2:1 的比例

**含义**：

- **框架（framing）**改变决策：把同一选项描述为"$50\%$ 保住 100 元" vs "$50\%$ 失去 100 元" → 不同选择
- 传统期望效用理论无法解释真实决策；行为经济学（behavioral economics）从此开枝散叶

### 决策场景里的应用

**为什么会员总是很难取消**（不是意外）：设计师利用了

- **Status-quo bias**：默认继续是路径最少阻力
- **Loss aversion**：取消 = 明显损失（"失去会员权益"）
- **Sunk-cost**：已付费的心理承诺

**如何设计更好的默认**：

- 器官捐赠"预设同意 vs 预设拒绝" → 显著改变捐赠率
- 退休储蓄"自动加入" → 参与率大幅上升
- 医疗决策 checklists 减少 anchoring

### 与其他框架的联系

- **贝叶斯理性人**：把先验+似然结合更新后验——[[posterior-distribution]]。真实人几乎从不这样做，除非严格训练
- **[[hypothesis-testing]]**：确认偏差 = 有意选择只支持 $H_1$ 的数据
- **[[monte-carlo-methods]]**：可得性偏差是"从最近记忆里采样"，样本严重非代表
- **[[pac-bayes-bound]]**：过度自信 = 低估参数不确定性
