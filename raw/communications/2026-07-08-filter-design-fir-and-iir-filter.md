[[FIR and IIR]]

- An FIR filter satisfies $a_{n}=0$ for $n\neq 1$: the output only depends on current and past values of **input** but not on past values of the **output**. Therefore it is a feed-forward system. 
- An IIR has infinite length delta response, which can only be a result of feedback.
