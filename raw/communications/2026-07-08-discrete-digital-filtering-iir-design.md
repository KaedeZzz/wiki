Uses Continuous-to-Discrete mappings.
1. Translate the filter specs in $\theta$ to analog specs in $\omega$
2. Design an analog filter, either using [[Continuous-to-Discrete Algebraic Transformations]] or [[Response Matching]]
3. Check if design obtained stability (and re-adjust if not)

note: response matching is more for FIR.
