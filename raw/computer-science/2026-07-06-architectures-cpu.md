The central processing unit fetches instructions from main memory and determines their type. Performs simple arithmetic and logic functions on data within the CPU; small, high speed memory, e.g. program counter, used to store temporary results.

Core internal components:
- registers (fast operand/result storage; includes special ones like program counter)
- ALU (arithmetic and logic)
- control (orchestrates operations)
