[[Source Coding]]
$N$ outcomes from a source $X$ _can be compressed_ into roughly $NH(X)$ bits.

Brief proof:
When a source $X$ produces $N$ independent outcomes, the string $x=x_{1}x_{2} \dots x_{N}$ is very likely to be one of the $\sim 2^{NH(X)}$ typical outcomes.
