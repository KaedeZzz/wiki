let $\mathcal l(X^{n})$ denote the length of the codeword assigned to $X^{n}$.
The expected code length is defined as the [[Expectation]] of length of codes in distribution of sequence:
$$
\mathbb{E}\{\mathcal l(X^{n})\}=\sum_{x^{n}}P(x^{n})\mathcal l(x^{n})
$$
where $x^{n}$ is a sample drawn from $X^{n}$
