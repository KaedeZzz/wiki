[[Information Theory]]
Goal: to compress a source producing symbols $X_{1},X_{2},\dots \in \mathcal X$ that are i.i.d. $\sim P$
For any $n$, a compression code is defined as follows:
- to each source sequence $X^{n}:=(X_{1},\dots,X_{n})$, the code assigns a *unique* binary sequence $c(X^{n})$, known as the *codeword* (for the source sequence).
