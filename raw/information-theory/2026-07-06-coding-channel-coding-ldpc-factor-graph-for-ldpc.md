Each column $j$ of $H$ is a variable node $v_{j}$.
Each row $i$ of $H$ is a check node $c_{i}$.
A one in entry $(i,j)$ means that variable node $v_{j}$ is connected to the check node $c_{i}$, i.e. code bit $j$ is involved in the parity check equation described by the $i$-th row.
