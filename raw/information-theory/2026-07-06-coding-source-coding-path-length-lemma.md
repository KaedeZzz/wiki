#ESSENTIAL 
In a [[Huffman Coding]] tree, all nodes (whether **leaves** that represent a sequence or **non-leaves** that represent a joint prefix of some sequences) will have an assigned **probability** that represents the probability of occurrence of this node.

**Summing probability of all nodes gives [[Expected Code Length]].**
