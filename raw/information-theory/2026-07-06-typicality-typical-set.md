The typical set $A_{\epsilon,n}$ with respect to $P$ is the set of sequences $(x_{1},\dots,x_{n}) \in \mathcal X^{n}$ with the property
$$
2^{-n(H(X)+\epsilon)}<P(x_{1},\dots,x_{n})<2^{-n(H(X)-\epsilon)}
$$
*"Sequences whose probability is concentrated around $2^{-nH(X)}$"*
Note the dependence on $n$ and $\epsilon$.
A sequence belonging to the typical set is called an $\epsilon$-typical seqeunce.
