An $(n,k)$ binary block code maps every block of $k$ data bits into a binary [[length-n Code]]word.
- rate: $\frac{k}{n}$

What makes a good code?
- rate $R=\frac{k}{n}$ as high as possible
- low probability of decoding error
- computationally efficient ways to encode and decode
