Code rate is "how much useful information is sent per channel use".

If each channel use carries a symbol from an alphabet of size $\lvert \mathcal{X} \rvert$, then one symbol can carry $\log_{2}\lvert \mathcal{X} \rvert$ bits in principle, so the rate as "bits per channel use" is:
$$
R=\frac{1}{n}\log_{2}M
$$
where $M$ is the number of codewords.
