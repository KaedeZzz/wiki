[[Prefix-free Code]]
1. The lengths are ordered inversely with probabilities, i.e. if $p_{j}>p_{k},l_{j}\leq l_{k}$
2. The two least probable symbols have the same length and are on neighbouring leaves in the binary tree. (They differ only in the last digit)
