[[Probability and Statistics]]
Probability space $\Omega$: 
set of all possible outcomes. We can call any subset of $A \subseteq \Omega$ an event.
Probability $P$: 
mapping function from events to a number in $[0, 1]$.
A probability space is described by describing a pair $(\Omega, P)$; that is, we must specify $\{ P(A),A\subset \Omega \}$.
