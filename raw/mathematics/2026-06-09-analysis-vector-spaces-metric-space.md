A [[Vector Space]] that has a distance function is a metric space.

A distance function maps two vectors to a non-negative real number. The function $\rho$ is a distance function if:
- $\rho(x,y)=0$ iff $x=y$
- $\rho(x,y)=\rho(y,x)$
- $\rho(x,y)\leq \rho(x,z)+\rho z,y$ for any $z \in V$
