*Vector space is a set of object to which addition and multiplication applies.*

A vector space $V$ is a collection of elements $x$ - vectors - with following axioms:
- $x+y \in V$, closure of addition
- $x+y=y+x$, addition is commutative
- $x+(y+z)=(x+y)+z$, addition is associative
- $x+0=x$, zero vector exists
- $x+(-x)=0$, additive inverse exists
- for $\alpha \in \mathbb{R}$ or $\alpha \in \mathbb{C}$, $\alpha x \in V$, scalar multiplication is closed
- $\alpha x+\alpha y=\alpha(x+y)$, scalar multiplication is distributive
- $\alpha(\beta x)=\beta(\alpha x)$, scalar multiplication is distributive
- $0\times x=0, 1\times x=x$, zero and unit scalar

Vector space is a group under addition.
