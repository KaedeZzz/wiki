A single operation algebraic system consists of a set $S$ and an operation $\star$ and is denoted $\langle S,\star\rangle$.

![[Closure]]

![[Associative Law]]

Algebraic system that satisfies associative law (and above) is a [[Semi-group]].

![[Neutral Element]]

Algebraic system that has neutral element (and above) is a [[Monoid]].

![[Inverse]]

Algebraic system that satisfies inverse (and above) is a [[Group]].

![[Commutativity]]

Algebraic system that satisfies commutativity (and above) is an [[Abelian Group]].
