The rank of a [[Matrix]] $\mathbf{A}\in \mathbb{C}^{m\times n}$is the number of independent columns and rows.
- column rank is the number of independent columns.
- row rank is the number of independent rows.
- they are equivalent.

A matrix is *full rank* if $\text{rank}(A)=\min(m,n)$.
A matrix is *rank deficient* if $\text{rank}(A)<\min(m,n)$
