[[Probability and Statistics]]
Given a probability space $(\Omega, P)$, a random variable is *a function $X(\omega)$ that **maps** each element $\omega$ onto a point on the real axis*.

For any set $A\subseteq(-\infty,\infty)$, define 
$$P(X\in A)=P(\{ \omega:X(\omega)\in A \})$$
A random variable is called _discrete_ if it is mapping to a finite or countable set.

A function of a random variable is still a random variable.

To fully define a random variable, we must define its range and the probability of the random variable taking those values.
